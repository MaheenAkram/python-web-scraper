# Python Web Scraper 🕸️

A Python-based Web Scraper built with CustomTkinter, Requests, and BeautifulSoup to extract product prices, news headlines, and custom data from public web pages, with Excel and CSV export functionality.

## ✨ Features

- Extract product prices from web pages
- Scrape news headlines
- Extract custom data using CSS selectors
- Export scraped data to Excel and CSV
- Simple desktop GUI built with CustomTkinter
- Input validation and error handling

## 🛠️ Technologies Used

- Python
- CustomTkinter
- Requests
- BeautifulSoup
- OpenPyXL

## 📋 Requirements

- Python 3.10 or newer
- Internet connection

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python main.py
   ```

## 📂 Project Files

- `main.py` — Desktop application interface
- `scraper.py` — Web scraping functionality
- `exporter.py` — Excel and CSV export
- `requirements.txt` — Required Python libraries

## ⚠️ Disclaimer

Use this tool responsibly and respect website terms of service, robots.txt rules, and applicable rate limits. Only scrape publicly accessible content you are permitted to use.
